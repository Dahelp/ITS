# ИТС · Авито — мобильный клиент

Внутреннее Flutter-приложение Android/iOS для одного подключённого аккаунта Авито. Серверный контракт: [API v1](../../docs/avito-mobile-api.md).

## Что реализовано

- Вход по email/паролю сотрудника; токен в Android Keystore / iOS Keychain, пароль не сохраняется. Возврат в приложение проверяет серверную сессию. При 401/403 локальная сессия и открытая переписка закрываются.
- Список, поиск среди загруженных чатов, фильтр непрочитанных, даты/время МСК, отметки новых/отправленных/прочитанных, пагинация.
- История, текст до 1000 символов, выбор/подтверждение отправки фото, просмотр фото, воспроизведение входящих голосовых.
- PDF/DOCX по временной ссылке на 7 дней; возможность отключить исходящую ссылку из истории.
- Ответственные, внутренние заметки, создание/редактирование/скрытие шаблонов; шаблон вставляется в поле, а не отправляется сразу.
- Устройства и выход с одного/всех телефонов. При сетевой ошибке выхода приложение сообщает ошибку и сохраняет сессию до подтверждённого отзыва на сервере.
- Опрос только на активном экране/в активном приложении, увеличение интервала при ошибках, резервное обновление истории при ошибке webhook-status. Уже загруженные страницы диалогов сохраняются при обновлении.
- Нет автоматического повтора отправки: после неопределённого сетевого результата предлагается обновить историю и проверить доставку.

## Запуск

Проверенная базовая среда: Flutter **3.24.3**, Dart **3.5.3**, Android SDK **35**, AGP **8.6.1**, Gradle **8.7**, JDK **17** (локальная сборка также с Java 21). Зависимости закреплены в pubspec.lock. Android 6+ (API 23), iOS 13+. Для распространения через магазины понадобится актуализация SDK/целевой версии и отдельная проверка требований магазинов, включая устройства Android с 16-КБ страницами памяти.

```text
cd mobile/avito_chat
flutter pub get
flutter analyze
flutter test
flutter run -d <идентификатор_телефона>
flutter build apk --debug
flutter build apk --profile
```

APK: `build/app/outputs/flutter-apk/app-debug.apk`; компактная внутренняя сборка — `app-profile.apk` (около 79 МБ). Обе имеют debug-подпись, это не магазинный релиз. Не содержат ключей Авито или паролей сотрудников. Backend закреплён на `https://its-center.ru/api/mobile/v1/avito/`; HTTP и автоматические перенаправления с токеном отключены. Готовая локальная profile-сборка сохранена в `outputs/mobile/its-avito-0.1.0-test.apk` от корня репозитория; бинарники не коммитятся.

При первом входе используются собственные данные сотрудника админки. Сначала включить ему чекбокс чата Авито в customers; обычные клиенты доступ не получают. **Ответ из обычной Android/iOS-сборки отправляется реальному покупателю.** Для первых проверок используйте согласованный тестовый диалог. Не сохраняйте токены и реквизиты покупателей в логах/скриншотах тестов.

Если сеть недоступна при старте, кнопка «Повторить подключение с сохранённой сессией» проверяет прежний токен без повторного ввода пароля. История и заметки на диск не кэшируются.

## Демонстрация без подключения к Авито

```text
flutter run -d chrome --web-renderer html --dart-define=DEMO=true
```

Любые email и пароль, локальные тестовые диалоги. Сетевая отправка и вложения в демо отключены. Демо явно помечено в интерфейсе. Web-сборка предназначена только для демонстрации; производственный вход в браузере запрещён. Не собирайте APK для реальных сотрудников с DEMO=true.

## iOS

Открыть `ios/Runner.xcworkspace` на macOS с Xcode после `flutter pub get` и `pod install` в ios. Выбрать свою команду Apple Developer и уникальный Bundle ID (сейчас `ru.itscenter.itsAvito`). Нет встроенных ключей подписи, push-сертификатов или настроек чужой команды.

```text
flutter build ios --debug --no-codesign
```

Unsigned Runner.app не устанавливается на обычный iPhone. Для тестирования на устройстве/через TestFlight потребуется Apple-подпись. Локально в Windows iOS-бинарник не собирался и нативные плагины на iPhone не проверялись. В GitHub Actions есть ручной необязательный job iOS без подписи; он не запускается обычным push.

## CI и публикация

`.github/workflows/avito-mobile.yml` анализирует Dart, выполняет тесты и собирает debug APK. Артефакт `its-avito-android-test` доступен 14 дней. Мобильные исходники исключены из rsync веб-сайта; этот этап не добавляет страницу в админку и не меняет серверный API.

## Осталось перед рабочим распространением

1. Пройти вход, доступы, переписку, фото, DOCX/PDF и голосовые на реальном Android и iPhone с тестовым покупателем. Автоматические тесты и демо не заменяют проверку нативного хранилища, файловых диалогов и аудио на устройстве.
2. Подключить FCM/APNs, регистрацию устройств и отправку push из webhook. Сейчас при закрытом приложении уведомлений нет.
3. Завершить оформление иконок iOS/запуска, постоянную подпись, актуализацию инструментов под требования магазинов и подготовку release/TestFlight.

Удаление сообщений, запись/отправка голосовых и типы сообщений, которые не поддерживает существующий backend Авито, клиент не обещает: показывает доступный текст/тип. Вложения-документы передаются ссылкой, а не произвольным вложением Авито.

Проверенные источники инструментов: [Flutter: платформы](https://docs.flutter.dev/platform-integration), [AGP 8.6](https://developer.android.com/build/releases/agp-8-6-0-release-notes), [защищённое хранилище](https://pub.dev/packages/flutter_secure_storage/versions/9.2.4).
