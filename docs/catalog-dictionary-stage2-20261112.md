# Этап 2 — управление справочниками, 12.11.2026

Статус: реализовано локально, публикация пока не завершена из-за таймаутов SSH. Не считать этап принятым до подтверждения receipt.json и проверки живого интерфейса.

Реализовано:
- Авторитетные определения и полная матрица применимости читаются из существующих catalog_property / catalog_property_rule после явной активации. JSON остаётся стартовым набором; установщик не перезаписывает управляемые определения исходным JSON.
- Новый экран /admin/catalog-properties/dictionary-edit?code=... и создание без code. Название, пояснение, варианты, архивирование, обязательность по типам; новые простые свойства text/decimal/integer/boolean/option/multi_option. Существующие код, тип и единица неизменяемы.
- Архивные значения не удаляются. Нельзя назначить архивный вариант новому товару; старое выбранное значение сохраняется. Архивное свойство не добавляется заново и перестаёт быть обязательным. Отключение применимости запрещено при известных значениях у данного типа товара.
- Admin + CSRF, глобальная версия справочника, блокировка конфликта редакторов, журнал состояния до/после. Версия правил включена в форму товара; устаревшая форма отклоняется. Код и ID вариантов сохраняются.
- Существующие пути карточки/YML и очереди получают новые определения. Связи с фильтрами не создаются этим этапом. Перенос старых данных учитывает изменение словаря в fingerprint правил.
