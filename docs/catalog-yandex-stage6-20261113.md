# Этап 6. Кабинет «Яндекс Товары»

Опубликован 13.11.2026. Адрес: https://its-center.ru/admin/plagins/yandex-tovars

## Изменения

- Открытие кабинета больше не зависит от синхронного вызова старого API Яндекса. Ошибки локальной диагностики обрабатываются без изменения товаров и XML.
- Список локальных YML-выгрузок: состояние XML, число предложений, дата внутри файла, время изменения файла, размер, дата выполнения задания в БД. Sitemap и RSS не относятся к этому списку.
- Проверка текущего фида спецшин без публикации. Поиск по артикулу/названию, отбор включённых и исключённых товаров, причины исключения с количеством.
- У включённых товаров раскрывается фактический XML предложения: название, цена, фото, производитель и характеристики после действующих преобразований.
- Единая функция причин исключения используется генератором и диагностикой; проверка изображения также общая. Сохранены категории, свободный остаток, правило цены, названия и характеристики предыдущих этапов. Повторяющийся артикул блокирует предпросмотр выгрузки с объяснением, как и реальную генерацию.
- Локальная читаемость XML не выдаётся за приём Яндексом. Ссылка на кабинет площадки доступна отдельно; автоматического статуса модерации через API в этом этапе нет.

## Как пользоваться

Открыть кабинет, нажать «Проверить текущую выгрузку и причины исключения». Выбрать состояние или причину, при необходимости найти артикул. Ссылка артикула ведёт в единый редактор характеристик. Предпросмотр показывает максимум 100 результатов; поиск позволяет уточнить выборку. Для заданий выгрузки есть отдельная ссылка. Расписание не изменялось.

## Проверка

На боевом сервере проверено 409 товаров: 136 включены, 273 исключены. У всех исключённых есть причины. Причины пересекаются: отсутствие свободного остатка/неподходящий статус — 273, неположительная цена — 19, пустой артикул — 13, скрытый товар — 4. Нулевой остаток является штатным исключением.

Сгенерированный в памяти XML до и после публикации совпал, за исключением даты формирования. Опубликованные XML не перезаписывались. В действующем файле спецшин 133 предложения: файл сформирован раньше проверки; это отдельное состояние, а не ошибка счётчика.

Проверены неизменность данных во время диагностики, серверный рендер кабинета и SHA256 установленных файлов. Между двумя проверками фоново изменился fingerprint таблицы product, поэтому нельзя утверждать, что сайт в целом не менялся в течение всего интервала; кабинет выполняет только чтение. Внутри контрольной диагностики изменения таблиц не обнаружены.

Локально: проверки структуры XML, защиты от внешних сущностей и обхода путей, причин исключения, совпадения генератора и предпросмотра, отображения страницы, отсутствия записи в БД/фиды; существующие тесты генератора и свободного остатка прошли.

В браузере открылась форма входа. Визуальная проверка авторизованной страницы не выполнена, серверный рендер проверен.

Предпросмотр состава и причин реализован для спецшин. Остальные YML представлены состоянием опубликованного файла; их правила генерации не менялись.
