# Этап 8. Единый рабочий процесс в админке

Статус на 13.11.2026: **опубликован и проверен на боевом сайте**. SSH восстановился после первоначальных таймаутов. Перед установкой получены свежие исходники всех 14 существующих файлов, изменения собраны поверх них. Публикация 22 файлов выполнена в 12:09 МСК с резервными копиями и проверкой SHA256. Адрес: https://its-center.ru/admin/catalog-workflow

## Рабочие разделы

- `/admin/catalog-workflow` — сводка каталога, поиск товара, основные очереди замечаний, состояние локальных YML и порядок работы.
- `/admin/catalog-workflow/product?id=357` — рабочая карточка конкретного товара: текущие замечания, итоговые SEO-поля, переходы в основной редактор, характеристики, названия, проверку качества, источники, предпросмотр спецшин и историю.
- `/admin/catalog-workflow/history` — единая история с фильтром по разделу и ID товара, по 50 событий на страницу.
- `/admin/catalog-workflow/landings` — обновляемая проверка активных SEO-привязок режима landing без соответствующих видимых товаров в категории и подкатегориях.

Открытие центра включает все товары, в том числе скрытые и без остатка. Сохранённый профиль не выдаётся за подтверждённые технические данные. Проверка SEO не обещает индексацию или позиции. Предпросмотр состава YML по-прежнему поддерживается только для спецшин; состояние остальных файлов доступно отдельно.

## Интеграция

В меню «Каталог и склад» добавлен «Рабочий центр каталога». Общая навигация добавлена в 12 существующих экранов: список/редактор характеристик, качество, замечания, справочники/редактор справочника, переносы, названия, связи фильтров, вывод категорий, основной редактор товара и Яндекс Товары.

Ссылки товаров из качества, замечаний и YML ведут в рабочую карточку. Внутри редакторов есть обратная ссылка на рабочую карточку выбранного товара. Исходные редакторы и их сохранение не заменяются.

Добавлен точный фильтр очереди `seo=effective`: число в сводке совпадает с количеством товаров с итоговыми SEO-замечаниями в очереди. Исправлена ссылка предпросмотра Яндекс Товаров: полный путь вместо `?preview=1`, который неверно разрешался через базовый URL админки. Пагинация нового журнала также использует полный путь.

## История и права

Объединяются существующие журналы характеристик, справочников, связей фильтров, названий и проверки замечаний. События конкретного товара не смешиваются с общими правилами или другими товарами.

Для вывода категории показывается только последнее сохранение из существующей таблицы, с соответствующей подписью. Полного журнала там пока нет. История изменений основных полей старого редактора товара в объединённый журнал не добавлялась: существующие записи не выдумываются. Подробности и доступные операции остаются в профильных редакторах.

Новые маршруты доступны только роли admin и только через GET. Менеджер получает отказ; даже POST с корректным CSRF отклоняется как неподдерживаемый метод. Центр не создаёт таблицы, не подтверждает факты, не меняет замечания и не запускает выгрузку при открытии.

- Проверены ссылки на реальные параметры редакторов: `group` для связей фильтров, `id` для вывода категории.
- Проверены экранирование текста, HTML-рендер четырёх новых экранов, права и GET-only, отсутствие изменений в исходных таблицах.
- Пройдены CatalogWorkflowDatabaseTest, CatalogQualityTest, CatalogQualityViewTest и CatalogPropertiesViewTest. PHP-синтаксис 22 файлов проверен.
- В браузере проверены локальные статические сводка и рабочая карточка. Формы предпросмотра отключены. На карточке нет горизонтального переполнения. Скриншоты содержат явную пометку локального предпросмотра.
- После входа пользователя проверен боевой интерфейс: поиск IT000007251 дал один результат, открылась рабочая карточка товара 357, выполнен переход в характеристики и возврат, предпросмотр YML сохранил отбор по артикулу, история показала только события выбранного товара. Кнопка предпросмотра в кабинете Яндекс Товаров ведёт по правильному полному адресу. Товарные формы не отправлялись.
- На боевом сервере: 1184 товара, 880 сохранённых профилей, 304 товара прежнего формата, 304 отложенные проверки, 13 замечаний по посадочным, 1202 события в объединённой истории. Счётчик итоговых SEO-замечаний — 71; переход в очередь дал ровно 71 товар и активный фильтр effective.
- Серверный рендер четырёх новых страниц, admin-only и GET-only проверены; контрольные суммы исходных таблиц до/после публикации совпали. Сама диагностика также не меняет данные.

Локальные цифры не отражают боевую БД. В частности, 13 замечаний по SEO-посадочным из этапа 7 при работе нового центра должны рассчитываться заново по боевым данным, а не копироваться как постоянный список.
