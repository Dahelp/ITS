# Корзина: очистка и удаление старых реализаций — 26.10.2026

История: `27b7833ad` добавлял уведомление сверху и управление количеством, `04543e91b` убирал старые modal-триггеры, `4207fa385` добавлял действия корзины, включая очистку. Эти изменения есть в рабочей ветке, но часть не была перенесена в master/боевые файлы. Последующая правка `80f31211e` / `5dd594a8d` убрала общую модалку на боевом сайте и добавила нижнее уведомление. В рабочей ветке из-за этого осталось два варианта уведомления. Текущее исправление объединяет обработку; весь локальный JS поверх сайта не копируется.

Результат:
- Одна функция showCartFeedback и один DOM-блок нижнего уведомления со ссылкой на корзину. Старое верхнее уведомление и его CSS удалены.
- Убраны функция открытия/закрытия модалки, её frontend-обработчики количества и удаления, четыре неиспользуемых backend-метода plusmodal/plusmodalcomplete/minusmodal/minusmodalcomplete.
- Старый cart_modal.php удалён из сайта. Вместо таблицы с неиспользуемыми кнопками AJAX получает маленький скрытый cart_state.php: количества, сумма, ID/ключи позиций и сообщение об ограничении остатка. Этот фрагмент реально используется для синхронизации шапки и кнопок, не является новой модалкой.
- В корзине есть «Очистить корзину» с подтверждением. Очистка, как и завершение заказа, использует один серверный emptyCart: удаляет товары, итоги, промокод и undo; меняет поколение черновика. Сессия пользователя не удаляется.
- Клиент очищает черновик только после подтверждённого сервером пустого состояния. После очистки форма скрывается, пустая корзина показывается корректно, несмотря на непустую HTML-разметку счётчиков.
- Данные формы после серверной ошибки читаются как одноразовые значения, а не остаются в сессии навсегда. Очистка также удаляет именно checkout-данные form_data, не затрагивая другие формы.
- Отдельное действие теперь называется «Сбросить данные оформления»: очищает доставку, контакты, комментарий, файл и согласие, оставляет товары, возвращает к шагу 1. Пустой черновик после этого не сохраняется повторно от технического переключения шага. Открытые вкладки получают событие удаления сохранения.
