# CR-01: три шага оформления — 26.10.2026

По решению владельца сохранены три шага; одностраничное оформление в этот этап не входит.

Вверху формы — кнопки шагов и прогресс «Шаг N из 3». Назад можно вернуться свободно. Переход с корзины сразу к контактам сначала открывает и проверяет получение; при ошибке остаётся шаг 2 с нативной подсказкой. На шаге 3 обязательность согласия, способа связи и типа клиента не теряется после смены шага.

Исправлена старая последовательность восстановления доставки: теперь состояние читается до сохранения пустых первоначальных полей.

Черновик хранится в localStorage этого браузера 24 часа. Записывается при изменении выбора, раз в 5 секунд для ввода и при pagehide/скрытии вкладки. При возврате восстанавливаются допустимые поля и предлагается продолжить с сохранённого шага. «Сбросить данные оформления» удаляет черновик и очищает поля, оставляя товары; «Очистить корзину» удаляет товары и черновик после подтверждения успешной очистки сервером. При запрете хранилища форма остаётся работоспособной и сообщает, что черновик не удалось сохранить.

Разрешённые поля: доставка/транспортная/склад/город/адрес, вид клиента/НДС/договор, имя/телефон/email/способ связи/комментарий. Не сохраняются CSRF-токен, honeypot, согласие и содержимое файлов. Если был прикреплён файл, после восстановления показывается напоминание прикрепить заново. Выборы select восстанавливаются только при наличии значения в актуальных options. Данные не вставляются через innerHTML.

Ключ разделён по guest/user-ID. После успешного оформления сервер меняет поколение черновика: предыдущие данные не восстанавливаются в новом заказе. При пустой корзине сохранение очищается. Корзина и остатки остаются серверными, в localStorage не переносятся.

Проверки: CheckoutProgressTest.js (срок, другой пользователь, успешный заказ/смена поколения, повреждённый JSON, whitelisted поля, ограничение длины, переходы и проверка получения); node --check, PHP lint. В браузере на боевой форме: пустая доставка не пропускает к контактам; курьер/город/адрес; сохранение имени, email, комментария и способа связи; перезагрузка; закрытие/повторное открытие вкладки; возврат к шагу 3. Согласие осталось выключенным. Заказ не отправлялся; тестовая позиция удалена, корзина снова пуста. Серверные успешные заказы и письма ради проверки не создавались.
