# Каталог: отборы и сортировки — 26.10.2026

На главной добавлена ссылка `/catalog/products?status=hit`. Выбор хитов и их показ на главной не менялись: это ручная отметка в админке. Общая выдача и категории используют существующий Product widget и один CatalogSelection. Параметры status: hit, new, sale, discount; дополнительные отборы — категория и только свободное наличие. Распродажа — ручная отметка sale; скидка — реальное снижение цены, эти понятия разделены.

Сортировки: свободный остаток с модификациями и резервом; цена вверх/вниз; средний рейтинг отзывов; популярность по количеству разных заказов с товаром; отметка новинки, затем ID новых товаров; размер скидки в процентах; название. Популярность не означает оплаченные или завершённые продажи и не меняет ручные хиты. При равных значениях используется ID для стабильной пагинации. Нулевая цена идёт в конце ценовых сортировок. Цена учитывает действующие акции; для товаров с модификациями совпадает с максимальной ценой, которую показывает общая карточка.

Выбор сортировки сохраняется в localStorage. Явный sort в ссылке имеет приоритет; без sort сохранённый выбор переносится в URL. При изменении атрибутов сохраняются status, in_stock, sort, perpage. Форма сохраняет выбранные фильтры, сбрасывая страницу. Старые sort=nal/price/rate поддержаны; rate теперь означает рейтинг отзывов, а не hit. Служебные GET-ключи маршрутизатора не переносятся в формы. Служебная общая выдача и параметры отбора закрыты noindex, follow; canonical категорий сохранён.

Размер страницы исправлен на 25/50/100 под сетку из пяти карточек; старые значения 24/48/96 нормализуются в 25/50/100. В категориях первые 10 карточек выводятся сразу, остальные позиции страницы догружаются существующим механизмом. Устранён старый предел догрузки 5 карточек. Вёрстка очищает предыдущие float фильтров, чтобы панель не уезжала вправо.
