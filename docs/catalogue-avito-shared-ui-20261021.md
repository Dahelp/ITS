# Комплекты, чат Авито и общие элементы сайта

21.10.2026.

- `/complete?category=...` и варианты сортировки: `noindex, follow`; основной `/complete` остаётся индексируемым. Canonical на основной каталог сохранён. Отбор по category не блокируется в robots.txt, поэтому поисковик может прочитать noindex. Существующий запрет обхода sort в robots.txt сохранён.
- Карточка в чате Авито учитывает `complete_id`: доступное количество полных комплектов определяется минимальным целым частным свободного остатка компонента и его количества в составе. Резерв вычитается; повторяющиеся компоненты суммируются. Единица — «компл.». Ссылка ведёт на публичный товар или комплект.
- Две компактные кнопки: «Открыть объявление», «Открыть товар». У CSS и JS чата версия по filemtime.
- Согласованное изображение менеджера с красным элементом подключено в общем decide-block. Боковые действия восстановлены без кнопки «Помощь»; общий z-index 1900 выше шапки и каталога, диалоги остаются поверх действий.
- ProductDeletion выполняет удаление в транзакции. Удаляет все фото галереи, прямые и обратные связи, фильтры, характеристики, избранное, сертификатные привязки, уведомления о наличии и складские строки. Удаление затронутого комплекта очищает весь его состав и галерею. Объявления Авито архивируются и отсоединяются. Общие файлы и отзывы сохраняются при наличии других ссылок.
- Заказы, заявки и переписка сохраняют собственные названия и суммы; product_id отсоединяется. У позиций заказа устанавливаются external=1 и mod_id=0.

Проверки: CompleteInventoryTest, AvitoListingCompleteTest, ProductDeletionTest (включая искусственную ошибку и откат).
