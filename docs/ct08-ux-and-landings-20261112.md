## Интерфейс

На компьютере удалены ограничения высоты и overflow у всей панели и fieldset. Прокручивается сама страница. В группах первые6 вариантов, остальные через «Показать ещё (N)»; обратная кнопка «Свернуть». Отмеченные значения всегда остаются видимыми. Без JS доступны все значения.

Нативные checkbox заменены аккуратными красными checkbox с белой галочкой, hover/focus/disabled. В forced-colors возвращается системное оформление.

Кнопки sticky bottom:0 без скролл-контейнера. Локальный DOM: footer.bottom720 при viewport720, внутренних прокруток0. На телефоне сохраняется одна прокрутка содержимого bottom sheet; у групп вложенных прокруток нет.

## План переходов (реализован в готовом пакете)

До «Применить» выбор черновой, URL/товары/счётчики ещё не меняются. После — обычная загрузка страницы, без промежуточных переходов после каждого checkbox.

- Один размер: `/category/shiny-dlya-vilochnyh-pogruzchikov/6.50-10`. Это существующая посадочная с прежними SEO-полями и правилами индексации.
- Добавлен EKKA: тот же путь плюс `?filter=83`. Комбинация noindex,follow; canonical на чистую посадочную размера. При выборе сначала нескольких разных групп основной становится первый выбранный вариант из группы с единственным значением. На уже открытой посадочной её основной вариант сохраняется.
- EKKA или Hengruida плюс один размер: посадочная размера сохраняется, оба производителя в query. OR внутри производителя, AND с размером.
- Два размера: путь одной размерной посадочной не подходит. Если другой однозначной группы нет — категория с `filter=235,236`, noindex,follow и canonical категории. При наличии единственного производителя может использоваться его посадочная с двумя размерами в query: заголовок производителя соответствует результатам.
- Прямой старый URL `/6.50-10?filter=236` сервер возвращает302 на категорию с обоими размерами, чтобы не показывать товары7.00-12 под заголовком6.50-10.
- Перенаправление на SEO-категорию сохраняет дополнительные фильтры/сортировку/наличие. Служебные параметры получают прежний noindex. Для основной страницы применяется её настроенный canonical, включая комбинации.
- Сам мультивыбор не создаёт новых SEO-записей. Существующие730 связей и HTML-ссылки посадочных не менялись. URL-адрес для подбора и самостоятельная индексируемая посадочная — разные вещи.
