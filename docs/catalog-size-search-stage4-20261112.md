Реализация:
- Новый CatalogSizeSearch строит проверенный индекс на чтении, не изменяя size_* поля товара и не создавая глобальные синонимы. Нормализуется только написание (x/х/×, десятичная запятая/нули); R и диагональное обозначение не приравниваются.
- confirmed + источник + валидный профиль + отсутствие условий обязательны. equivalent работает для шин/колёс; compatible — для камеры/ленты/диска/кольца/цепи только когда запрос явно распознан как соответствующий тип. Если тип не распознан парсером, совместимость не расширяет выдачу. Условные связи и черновики автоматически не участвуют.
- Отдельная catalog_size_relation_anchor фиксирует основной размер и hash вида связи, размера, источника, условий и профиля. Изменение карточки/основания блокирует устаревшую эквивалентность. Сохранение нового подтверждения обновляет metadata в той же транзакции, что профиль. Изменить основной размер или тип при неизменённом подтверждённом отношении нельзя без повторной проверки/нового основания либо перевода в предложение. Неизменённые связи не получают новые anchors автоматически.
- Явный CLI bootstrap при установке создаёт anchor для уже подтверждённой связи только если прежний профиль и действующий размер совпадают. На боевом сервере ожидается одна связь IT000007251, 12-16.5 / 33x12-20. Профили, факты и статусы не подтверждаются и не редактируются установщиком.
- Поиск и typeahead используют общий provider. Существующие результаты и сведения кроссов сохраняются; дубли ID удаляются. Связанное совпадение получает причину ранжирования; основной размер также гарантированно находится. В поисковой странице есть пояснение для альтернативного/совместимого совпадения.
- Фасеты добавляют существующие ID основного и подтверждённого альтернативного размера только этому товару, сохраняя прежние связи. Новые пункты фильтров/посадочные не создаются. Общий bridge обеспечивает счётчики и применимость прежних адресов. Согласованность публичной карточки/YML обеспечивается anchor_valid в проекции подтверждённых атрибутов.
- В редакторе характеристик добавлен статус участия каждой сохранённой связи в поиске и причина исключения.
- readAllProfiles расширен необязательным набором ID; индекс читает связанные профили пакетами до200 фиксированным числом запросов, без запроса на каждую карточку.
