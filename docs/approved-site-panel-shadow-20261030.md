# Подтверждённая тень блоков — 30.10.2026

По прямой команде пользователя опубликована точная тень класса shadow из блока desc-prod-inner bg-light shadow: 0 0.1rem 2rem rgba(46,46,46,0.1). Предыдущая попытка общей стилизации была отдельно отменена. Новое правило меняет только box-shadow, не переносит bg-light, padding, размеры, сетку, border или radius.

Единая переменная --site-block-shadow применяется к структурным панелям шапки, B2B, каталога, FAQ, размеров, товаров, техники, статей, услуг, консультации, комплектов, сравнения, отзывов, кабинета и подвала, а также к теневым псевдоэлементам секций. Учитываются существующие shadow, shadow-sm и shadow-lg. Кнопки, поля, состояния фокуса и всплывающие окна не затронуты.

Браузерная проверка после публикации: главная, каталог цепей, категория цепей, товар, контакты, комплекты, техника, статьи, услуги. На этих девяти страницах 180 крупных блоков с тенью совпадают с образцом; отличающихся теней среди проверенных крупных поверхностей нет. Проверены фактические computed styles. Это проверка общих шаблонов, не обход каждого URL сайта. Отчёт: outputs/approved-shadow-audit.json. Снимок: outputs/approved-shadow-home-live.png.
