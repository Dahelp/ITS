# Фильтры диалогов Авито

В админке и мобильном приложении 0.3.0 доступны «Все чаты», «Мои чаты», «Без ответственного» и выбор сотрудника. «Мои» означает назначенные текущему пользователю; это фильтр списка, права доступа и получатели push не меняются. Фильтр непрочитанных применяется независимо. Поиск работает по загруженным результатам.

Выбор ответственного сохраняется отдельно для каждого пользователя: в браузере — localStorage, на телефоне — защищённое хранилище. Выбор «Все чаты» сбрасывает только ответственного. Если сохранённый сотрудник больше недоступен, восстанавливается «Все чаты».

API `chats` принимает `assignee=all|mine|unassigned|<user_id>`, по умолчанию all. Возвращает `chats`, `next_offset`, `has_more`, `actor_id`, `managers`; строки содержат `assignee_id` (0 без назначения) и `assigned_to`. Следующая страница использует `next_offset`, а не число совпадений. Сервер сканирует до пяти исходных страниц за запрос; если совпадений пока нет, но `has_more=true`, кнопка загрузки продолжает поиск среди старых диалогов.
