# CR-02 — способы оплаты, 26.10.2026

Опубликовано: физлица — карта, QR-код, банковские реквизиты; наличные только при самовывозе. Юрлица — только реквизиты, выбираются автоматически.

Выбор на шаге 3, отражается в итогах всех шагов, сохраняется в заказе, доступен покупателю, администратору и в письмах. Сервер повторно проверяет тип клиента из учётной записи и способ доставки. При смене доставки недоступные наличные сбрасываются. Старые заказы имеют «Не указан».

Это выбор способа оплаты при оформлении; подключение эквайринга и проведение платежей не входят в изменение.

Постоянные технические надписи и кнопка удаления черновика убраны. Автосохранение и предложение продолжить незавершённое оформление сохранены. Очистка корзины остаётся только на шаге 1.

Проверки: PHP policy/model/mail fixtures и JS policy/progress tests прошли. На боевой странице проверены четыре варианта для физлица при самовывозе и автоматические реквизиты для юрлица. Тестовая корзина очищена. Настоящие заказы, платежи и письма не создавались.
