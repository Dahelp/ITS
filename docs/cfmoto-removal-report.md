# Отчёт об устранении обозначений CFMOTO

Дата выполнения: 8 октября 2026 года.

## Карта URL

| Старый URL | Место упоминания | Новый URL | Действие |
|---|---|---|---|
| `/technics/kvadrocikl/sf-moto` | Страница производителя техники | `/category/atv` | `301 Moved Permanently` |
| `/technics/kvadrocikl-moto-cf-c-forse-400l-eps-x4-eps` | Страница модели техники | `/category/atv` | `301 Moved Permanently` |
| `/technics/kvadrocikl-moto-cf-500-x5-basic` | Страница модели техники | `/category/atv` | `301 Moved Permanently` |
| `/technics/kvadrocikl-moto-cf-500-x5-ho-eps` | Страница модели техники | `/category/atv` | `301 Moved Permanently` |

Нейтральная целевая страница называется «Шины для квадроциклов» и сохраняет существующий каталог товаров без изменения карточек EKKA.

## Изменения данных

- Удалена одна запись производителя техники и три связанные записи моделей.
- Удалены 20 привязок типоразмеров только к этим трём моделям техники.
- Удалена отдельная запись производителя из справочника кроссов; связанных кросс-номеров у неё не было.
- Из 18 описаний объявлений удалена фраза с товарным знаком, без изменения товара, цены или характеристик.
- Три исторических URL в журнале чатов заменены нейтральным URL категории.
- Удалены 13 WebP/AVIF-файлов: логотип производителя и изображения трёх моделей в вариантах `baseimg`/`mini`.
- Кросс-номер фильтра `CF500` не относится к производителю техники, сохранён в БД и sitemap без изменений.

## Sitemap, метаданные и структурированные данные

- Старые страницы исключены из текущего `sitemap.xml`.
- Генератор sitemap теперь включает только видимые записи техники.
- Ранние редиректы срабатывают до загрузки БД, поэтому старые URL не формируют прежние title, description, OpenGraph, canonical, breadcrumbs или JSON-LD.
- Конечная страница `/category/atv` возвращает собственные нейтральные метаданные и структурированные данные.

## Проверки

- Повторный аудит БД: 0 совпадений по вариантам товарного знака и полным названиям удалённых моделей.
- Три PDF (27 страниц суммарно): совпадений в текстовом слое и видимой маркировки на отрендеренных страницах нет.
- Старые URL: локально возвращают `301` на `/category/atv`.
- `/category/atv`: локально возвращает `200`; в HTML контрольных обозначений нет.
- Тесты редиректов/sitemap, товарных вкладок, размеров изображений, SEO-размещения и FAQ Schema.org проходят.

## Публикация

После развёртывания необходимо повторить HTTP-кроулинг публичного домена, пересоздать sitemap штатным cron-заданием и отправить его в Google Search Console и Яндекс Вебмастер. Доступ к этим кабинетам в локальном окружении не предоставлен.
