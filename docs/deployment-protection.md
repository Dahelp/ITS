# Защита публикации на Beget

Деплой сайта разрешён только через `.github/workflows/deploy-beget.yml` и окружение GitHub `production`. В окружении разрешена только ветка `master` (не одноимённый тег). Ключ `PRODUCTION_SSH_KEY` хранится в окружении, а не в общих секретах репозитория.

Workflow делает checkout точного `github.sha` и сверяет его с текущей вершиной master через GitHub API. Проверка выполняется до настройки SSH и повторяется перед каждым шагом обращения к серверу. Ошибка API, другая ветка/событие, несовпадение checkout или устаревший коммит останавливают процесс. Все публикации используют общую очередь `its-center-production`; уже идущая запись не прерывается новым запуском.

Для master запрещены force-push и удаление, включая администраторов. Обычные коммиты и merge разрешены. Ручной запуск поддерживает `verify_only=true`: только проверка ветки, коммита и SSH, без rsync, установки зависимостей, миграций или изменения сайта. Произвольный ref/SHA для публикации не принимается.

Прежняя проверка неизменного восстановительного baseline заменена проверкой актуального master: восстановленные исправления уже входят в master, а навечно закреплённые старые хеши препятствовали бы следующим законным обновлениям.

Проверки: `tests/DeploymentGuardTest.cjs`, actionlint. Операционные результаты и проверка настроек GitHub сохраняются в `outputs/deploy-protection/`, вне Git. Настройка защиты публикуется с `[skip ci]`, затем проверяется вручную с `verify_only=true`; общий деплой сайта для установки защиты не запускается.

Настройка применена 14.11.2026. Проверка из актуального master: https://github.com/Dahelp/ITS/actions/runs/43626293755 — успешно, все шаги записи на сервер пропущены. Запуск из другой ветки: https://github.com/Dahelp/ITS/actions/runs/43626408249 — отклонён окружением production до выполнения шагов.

Общий секрет BEGET_SSH_KEY удалён после успешной проверки PRODUCTION_SSH_KEY. Устаревшие процессы Deploy chain filter repair, Audit accumulated project updates и Export low-stock tires отключены. Старые версии workflow без окружения production больше не получают SSH-ключ.
