# Комплект EKKA P350, 16.10.2026

## Доработка снятия с публикации

Нулевые/неактивные комплекты теперь отсекаются и автоматической, и ручной XML-выгрузкой (включая экспорт одного объявления). Для них не отправляются цена и нулевой остаток через API.

Добавлен CompleteAvitoPublication: после рабочего обновления остатков InventorySyncService и сохранения комплекта он сверяет статусы с Авито, отправляет положительные остатки и при необходимости запрашивает обработку файла `/autoload/v1/upload`. По [официальной инструкции Авито](https://www.avito.ru/autoload/documentation), исключённое из файла объявление после обработки переносится в архив. Проверено через API профиля: автозагрузка включена и использует `https://its-center.ru/avito/refresh-tovars`.

В `avito_complete_publication` хранятся ожидаемое состояние, факт отправки данных, подтверждённое состояние Авито, время запроса и ошибка. Принятие запроса автозагрузки не считается подтверждением архива: завершение фиксируется только после проверки статуса объявления через API (`old`/`removed`; при восстановлении — `active`). Неуспешные попытки остаются в очереди; повторные обращения выполняются при следующих обновлениях остатков, с паузой не менее пяти минут после ошибки и тридцати минут между запросами ещё не обработанной автозагрузки. Статусы проверяются повторно каждые тридцать минут при наличии вызовов обработчика. CLI для ручного повтора: `php8.2 bin/sync_complete_avito.php`.

Тест `tests/CompleteAvitoPublicationTest.php` проверяет переход 8→0→архив→8→активно на подставном API, отсутствие отправки цены/остатка при нуле, отсутствие нулевого комплекта в XML, ожидание подтверждения и повтор после ошибки. Боевые остатки ради теста не обнулялись. После установки реальный API подтвердил текущее активное объявление: checked=1, confirmed=1, pending=0, errors=[].

Резервная копия до доработки: `tmp/backup-complete-publication-20261016/code.tar.gz` на сервере.

## Первоначальное добавление

На сайте создан комплект ID 25: 29х9-14 (товар 31, артикул 9541), 2 шт.; 29х11-14 (товар 30, артикул 9542), 2 шт. Заполнены название, категория, описание, SEO title/description/keywords, ссылка, статус, основное изображение и галерея оригиналов.

Подтверждённое объявление Авито: 2444178586, внутренняя запись 140. Его описание явно указывает P350, оба размера и цену за четыре шины. Ошибочная связь с артикулом 9541 заменена на complete_id=25. API подтвердил цену 42400, остаток 8 комплектов, stock_mismatch=0, errors=[].

В существующих 24 комплектах не найдены точные соответствия остальным импортированным объявлениям комплектов: 2444211606 (P377), 3627739485 (P354), 2444243190 (P348/P357), 2444312908 (26-дюймовый P350), 3628050093 (P349). Совпадение размеров без модели не считается достаточным. EOS, Mars и другие названия не приравниваются к P-моделям без подтверждения.

В формах добавления и редактирования комплекта появилось поле «ID объявлений Авито». Допускается несколько импортированных объявлений через запятую. Артикулы берутся из состава, отдельного артикула комплекта не требуется. Объявление не может быть связано одновременно с двумя комплектами. При удалении привязки оно переводится в архив. Обычная синхронизация и XML-выгрузка включают комплекты; API отправляет количество полных комплектов, Quantity обозначает «за 4 шт.».

Цена: сумма актуальных цен компонентов за вычетом скидки на единицу, умноженных на количество. Наличие: минимум целых частных остатка компонента и количества в комплекте. Скрытый или отсутствующий компонент блокирует наличие.

Исправления: создание таблицы с подчёркиванием через xdispense; пустое фото при создании; числовая категория и допустимый статус по умолчанию; параметризованная замена состава; пустая цена подставляется из товара, пустая скидка равна нулю; исправлен порядок полей сохранения галереи; исправлена константа настройки загрузки фото.

Проверки: PHP lint всех изменённых файлов; tests/CompleteAvitoTest.php; интеграционная проверка создания без фото, пустых полей, изменения количества в составе с очисткой временных записей; HTTP 200 и визуальная проверка опубликованной карточки. Прямой просмотр админки браузером потребовал входа; поле проверено в шаблонах и серверной логике.

Резервные копии на сервере: tmp/backup-p350-20261016/code.tar.gz и storage/p350-complete-backup-20261016.json. Код Авито взят с актуального рабочего сервера перед изменением, чтобы сохранить имеющиеся там доработки.
