# Корзина без модалки: общая правка — 26.10.2026

Причина: в боевом общем main.js оставалась ветка, которая при успешном add/addcomplete открывала cart_modal, хотя локальная ветка содержала отдельные улучшения корзины. Также Bootstrap-атрибуты открытия корзины оставались в общей карточке, сравнении и избранном.

Исправлено в общем обработчике:
- успешное AJAX-добавление обновляет счётчик и кнопки, показывает короткое уведомление со ссылкой на корзину и остаётся на исходной странице;
- неполный/ошибочный ответ не превращается в сообщение об успешной покупке;
- старые вызовы открытия корзины переходят на /cart/view;
- убраны Bootstrap-атрибуты из общей карточки, сравнения и избранного;
- удалена разметка общей модалки корзины из partials/modals.php. Формы обратного звонка, наличия, входа и покупки в один клик не менялись.

CartNoModalTest.js выполняет реальный callback обработки ответа: add, addcomplete, ошибка, предупреждение об остатке, обновление счётчика и запрет вызова модалки. Дополнительно проверяет legacy-переход и отсутствие modal-атрибутов в общих шаблонах.

В браузере на боевом сайте проверены добавление из общего списка хитов и со страницы товара: модалки нет, страница остаётся прежней, счётчик меняется 0→1, появляется уведомление. «В корзине» на странице товара и корзина в шапке ведут прямо на страницу оформления. Тестовая позиция удалена, корзина снова пуста; заказ не отправлялся.

Публикуются только точечные изменения поверх текущих боевых файлов, без подмены общего JS всей локальной веткой. До замены сохранена закрытая серверная копия `.codex-deploy/cart-no-modal-20261026/before.tar.gz`.
