Подтверждённые поля с источником из единой базы используются в карточке товара и при формировании фида спецшин. Для остальных полей сохраняются прежние значения. Все 880 черновых профилей и 304 отложенных замечания сохранены; автоматических подтверждений нет.

Как работать

  1. Открыть единый каталог и нужный товар.
  2. Для будущей проверки сохранять сведения как «Исторические данные» или «Предложение» — они не заменяют публичные характеристики.
  3. После сверки выбрать «Подтверждено», указать документ/фото/источник и сохранить. Подходящие подтверждённые поля сразу используются карточкой.
  4. В блоке «Подключение к сайту и YML» отображаются поля, фактически выбранные из сохранённой версии. Несохранённый предпросмотр ничего не публикует.
  5. Фид получает изменения при формировании задания обновления №32. Рабочая ссылка фида сохранена.

Границы подключения

  • Неизвестные, неподтверждённые и противоречивые новые значения не подменяют старые поля. Неверный профиль/сочетание свойств отклоняет подмену.
  • Взаимозаменяемость действует только для конкретного товара, неизменившегося основного размера и подтверждённой связи. Условные связи не превращаются в безусловные; частично проверенный старый список размеров не обрезается.
  • Отдельные режимы нагрузки сохраняются отдельными строками. PR, индексы, давление и единицы не выводятся догадкой.
  • Название, H1, адрес, идентификатор, цена, остатки и фильтры каталога этой связкой не редактируются.
  • Применены только изменения этого этапа поверх текущих серверных версий карточки. Параллельные локальные правки оформления/корзины не публиковались.
