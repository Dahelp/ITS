# Параметры шин Авито — 22.10.2026

Справочники взяты из файлов продавца «Шины, диски и колёса — Шины для грузовиков и спецтехники» и «Мотошины», шаблоны от 15.10.2026. Исходные диапазоны и SHA256 записаны в app/data/avito-tire-dictionaries.json. Это датированный снимок, не автоматическое обновление справочника Авито.

Редактор использует списки с поиском. «Другое» доступно для высоты профиля, где оно есть в справочнике. Текущие нестандартные значения сохраняются с предупреждением. Тип «Для спецтехники» либо «Грузовая» определяется по категории. Мотошины имеют отдельный профиль.

При создании и синхронизации объявления размеры заполняются из характеристик товара, затем из названия. Кнопка в редакторе повторяет заполнение после явного нажатия; результат нужно сохранить. Несколько размеров в комплекте требуют ручного выбора. Для 6.50-10: ширина 6.50, профиль «Другое», диаметр 10. Размер диска 5.00F-10 даёт только диаметр 10: ширина диска не становится шириной шины. Самостоятельно введённые заполненные параметры при обычной синхронизации сохраняются.

Проверка загрузки: отчёт 620242395 остановлен с событием 307, поскольку Авито получил более новую версию файла. Публичный XML отвечает HTTP 200 и содержит 136 объявлений. В следующем отчёте 620242723 обнаружены два объявления с ошибками размеров: its-11668 и its-12032; значения исправлены по характеристикам товаров. Повторная загрузка запрошена после исправления. Принятие запроса не означает завершение обработки Авито.
